# KINETIC · 动势试炼 · v1.5

一个可离线运行的第三人称浏览器跑酷 demo：一张悬浮训练地图、一个带关节动画的原创装甲人形，以及 Warframe 战甲本体的通用移动机制。

v1.5 优先改善操控响应：独立起步、急停与转向参数，保留高速空中转向的动量；跳跃和翻滚有 140 ms 输入缓冲；快速转视角开火使用当前方向与枪口位置。角色重做曲面胸背甲、头盔面罩、前臂、小腿和肩部轮廓，持枪移动保留轻微重心与肩部运动。三把枪、机器人、近战、改键和 Shift 长短按规则继续保留。研究来源与自定参数见 [RESEARCH.md](RESEARCH.md)。本机开发目录的 `releases/` 保留 v1.0—v1.4 旧包。

这一版建议先体验 **W 起步 → 松手急停 → W/S 反向移动**，再尝试 **滑铲 → 子弹跳 → 点按瞄准 → 空中翻滚 → 着地续翻滚**。菜单「调整移动与瞄准」可分别改变起步、松键制动与转向响应。默认 12.5 m/s 奔跑速度下，平地起步约 150 ms，松键约 117 ms / 0.63 m 停下；这些是本 demo 的测试值。提前输入只短暂等待动作可用，不增加空中动作次数。

## 开始试玩

双击 **START_DEMO.cmd**，自动启动本机服务并打开浏览器。已提供编译产物 `dist/`，不需要先安装 npm 依赖。运行环境需要 Node.js 22+（当前电脑已安装）。

也可以在此目录运行 `node serve.mjs`，然后打开 <http://127.0.0.1:8771/>。服务仅监听本机，运行资源全部本地提供。不要直接双击 `dist/index.html`，浏览器 ES module 需要 HTTP 服务。

推荐 Chrome / Edge 桌面浏览器。点击「进入训练场」后，鼠标直接转向，无需按住左键；Esc 暂停并释放鼠标。在不支持鼠标锁定的嵌入浏览器中，自动使用画布内鼠标跟随，也支持方向键；光标到达窗口边缘时无法继续同向转动。完整的无限转向需要支持 Pointer Lock 的浏览器。

试玩结束后可双击 **STOP_DEMO.cmd** 停止由启动脚本创建的本机服务。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 / 奔跑开关 | WASD / 长按 Shift 0.25 秒切换，松开后保持；再次长按关闭 |
| 蹲行 / 滑铲 | 按住 C（也支持 Ctrl，浏览器推荐 C） |
| 跳跃 / 二段跳 | 空格 / 空中再按空格 |
| 子弹跳 | 蹲伏或滑铲时按空格，朝准星方向发射 |
| 翻滚 / 空中翻滚 | Q，或轻点 Shift；WASD 选择方向 |
| 瞄准 / 滑翔 / 取消动画 | 地面右键瞄准；空中点按取消子弹跳或二段跳旋转，按住缓降 |
| 瞄准侧移 / 后退 | 保持右键 + A/D/S，上半身朝向准星 |
| 左右肩镜头 | V |
| 纵向 / 横向蹬墙 | 靠墙时按住空格，移动方向决定向上或沿墙 |
| 壁面攀附 / 跳离 | 空中贴墙按右键 / 攀附时按空格 |
| 攀越边缘 | 面向可达边缘并按住方向和空格；重新按 C 可取消 |
| 空中滑踢 | 空中按 C；落地可接滑铲 |
| 绳索 | 靠近按 X 上绳，WASD 沿线移动，空格跳离，X / C 下绳 |
| 直接俯冲落地 | 空中 G，Q 翻滚可取消 |
| 重落地取消 | 着陆前按 C 滑铲、Q 翻滚或进入瞄准滑翔 |
| 射击 / 换弹 | 鼠标左键 / R |
| 快速切枪 | F 切回上一把，1/2/3 直选，滚轮或 [ / ] 循环 |
| 复位 / 切换训练区 | Backspace / 数字小键盘 1—6，也可在菜单选择训练区 |
| 指南 / 暂停 / 计时路线 | H / Esc / T |

推荐连招：**W + Shift → C + 空格 → 松开 C → 点按右键收起旋转 → 转动鼠标 → 空格 + Q → 按住右键滑翔 → C 着陆**。

也可使用：**普通跳跃 → 右键滑翔并转向 → C + 空格空中子弹跳**。这会用掉剩余的第二跳。转动镜头本身不会把既有水平惯性瞬间改成新的方向；方向输入持续修正轨迹，新的子弹跳或翻滚按当时视角/方向发力。

瞄准取消是真正结束前一个旋转动作，松开右键不会恢复旧动画。它不会补充二段跳、空中翻滚次数或滑翔时间。保持瞄准时，新跳跃、翻滚、滑踢优先；翻滚结束可接回滑翔。尚在进行中的翻滚和俯冲不被瞄准取消；俯冲仍可用翻滚取消。

以上为默认按键。按 **Esc → 自定义按键** 可为每个动作设置主键和备用键，支持鼠标左/中/右键及两个侧键；主键冲突自动互换。按键、鼠标灵敏度、瞄准倍率、Y 轴反转、肩侧偏好会保存在当前浏览器，刷新后仍有效。Esc 固定用于暂停/取消录入，系统保留键不能绑定。可单独关闭“轻点冲刺键触发翻滚”。

## 棍杖与单手剑

菜单 **近战武器与动作** 可以选择武器、查看连段和直接开始练习；训练中 **Z** 切换。武器选择也保存在当前浏览器。

| 基础动作 | 默认输入 | 棍杖 / 单手剑表现 |
| --- | --- | --- |
| 原地连击 | E | 棍杖横扫 → 回扫 → 转棍下劈；单手剑斜斩 → 反手斩 → 过顶劈斩 |
| 前进连击 | W + 攻击 | 保持前进的三段挥击 |
| 格挡连击 | 右键 + 攻击 | 直刺 → 上挑 |
| 突进连击 | W + 右键 + 攻击 | 突进刺击 → 追击；位移经过地图碰撞处理 |
| 滑铲攻击 | 滑铲中攻击 | 棍杖旋扫 / 单手剑旋斩，保留滑铲动量 |
| 空中连击 | 跳跃后攻击 | 三段空中挥击；保留水平惯性，不恢复跳跃次数 |
| 重击 | 地面鼠标中键 | 棍杖蓄力转棍 / 单手剑蓄力横斩 |
| 下砸 | 空中向下瞄准后攻击 | 按视角向地面定向下砸；空中鼠标中键为重型下砸；接触地面后显示冲击环 |

点按一次只出一段，在收招前可输入下一段；按住攻击键会连续挥击。改变前进/瞄准输入会在下一段切换连招类型。Q 翻滚和空格跳跃可以中断挥击；中断后先松开攻击再重新按，避免持续按键立即抢回控制。松开攻击，再点按右键，可以从普通挥击回到持枪瞄准或空中滑翔。保持右键时再攻击则进入格挡连段。

下砸不被瞄准取消，仍可用剩余次数内的空中翻滚或跳跃中断；切换武器不取消正在进行的下落。向下看超过约 40° 时，普通攻击触发定向下砸；按住后退仍可作空中挥击。直接俯冲 G 保持原来的陡降入口。角度、速度与取消窗口是本 demo 的调校值。

**旧按键迁移**：首次进入 v1.4，将 Shift、枪械、近战、复位和训练区快捷键更新为本轮布局；无冲突的其他移动改键保留。旧配置备份在当前浏览器的 `kinetic.bindings13Backup`。此迁移只运行一次，之后自行改键不会被覆盖。请以 HUD 和设置面板为准；轻点 Shift 不改变奔跑开关，暂停/复位会清除开关。

动作按 Warframe 的公开近战输入分类独立编排，**没有声称完整复刻 Clashing Forest、Iron Phoenix 等具体姿态 Mod**。近战挥击和下砸可伤害机器人，遵守距离、挥击范围、遮挡和单次接触限制；尚未包含连击倍率、自动招架、处决和 Mod 系统。

一次离地中，地面子弹跳后可以二段跳；空中使用子弹跳占用第二跳。空中翻滚单独计次。成功蹬墙、换墙攀附和落地刷新空中动作；滑翔与攀附有计时限制。普通冲刺与蹬墙没有耐力条。近墙可重新选择跳离方向。

## 枪械与机器人

菜单 **枪械与机器人训练** 可选择武器及「机器人对战 / 静态靶场 / 自由跑酷」。

| 原创枪械 | 开火 | 弹匣 | 换弹 | 基础伤害 |
| --- | --- | --- | --- | --- |
| 曙光自动步枪 | 按住连射，9 发/秒 | 30 | 1.45 秒 | 18 |
| 隼半自动手枪 | 每次按下 1 发 | 12 | 1.10 秒 | 42 |
| 碎星霰弹枪 | 每次按下 8 颗弹丸 | 6 | 1.90 秒 | 每颗 13 |

这些是本 demo 的训练参数。右键缩小散布，头部伤害为两倍；准星射线决定目标，再从枪口检查遮挡。每把枪独立记录弹匣，备用弹药无限。R 换弹；切枪、近战会中断未完成的换弹。自动步枪空仓且继续扣扳机会换弹，半自动武器空仓后再扣扳机会换弹。滚轮固定用于切枪，也有可重绑的上一把/下一把动作。

射击可结束子弹跳或二段跳旋转，但不补充空中资源。右键可接滑翔；新翻滚、下砸、攀越和上绳期间暂不能开火。近战优先于保持中的射击，松开再按射击可回到枪械。换弹可在移动和空中继续。

四个机器人在主广场巡逻、绕障追击和横移，开火前亮红灯约 0.48 秒，弹道可躲避。击倒后 6 秒重新出现。战甲有 80 护盾与 100 生命，脱离伤害 4 秒后恢复护盾；被击倒 2.5 秒后返回起点，重生有 3 秒保护。静态靶场的机器人不移动、不攻击。计时路线自动关闭机器人，之后可从菜单重新开启对战。

## 地图区域

1. 起点广场：平地加速、连招、动量保持。
2. 滑铲通道：1.02 米净高通道与两级翻越平台。
3. 蹬墙回廊：平行长墙、垂直高墙、墙顶落脚处。
4. 断桥飞跃：实际深坑与不同高度的落脚平台。
5. 高空绳索：可上下、双向平衡行走与跳离的倾斜绳索。
6. 斜坡平台：连续坡面、台阶、不同高度落地。

T 可启动 8 个检查环的可选计时路线，最佳时间保存在此浏览器；换区、复位或落出地图会取消本次计时。

## 实现与边界

- Three.js WebGL 渲染；120 Hz 固定物理步长，与显示帧率分离；显示层插值共享给角色和镜头。
- 动量驱动的独立运动控制器，带输入缓冲、短暂离地宽容时间、空中转向、站立净高检查、阶梯与斜坡支撑、高速碰撞细分、镜头避障。
- 角色使用程序生成的原创装甲人形与关节姿态动画，**不是官方圣剑模型或官方动作素材**。前伸头盔、分层胸背甲、修长四肢和装甲关节均为本项目几何；三把枪也采用原创程序模型。
- 瞄准时躯干与头部跟随视角，双手对齐枪柄/护木，腿部按侧移与后退方向迈步。切换姿态保留当前显示姿势后快速混合；动作输入无需等待视觉过渡结束。
- 这是通用跑酷机制的独立近似实现，速度、重力、动作时间和动画没有原作实测标定。菜单可调整手感。碰撞采用轴对齐身体包围体与矩形关卡，适合该训练场；不能直接当成任意复杂模型的通用物理引擎。
- 机器人使用本训练场主广场的平面导航网格，不会跑酷或追上高台；不包含战甲技能、指挥官、Archwing、K-Drive、联网和手柄/手机触屏控制。

动作设计参考：[Warframe 官方入门指南（Parkour / Advanced Maneuvers）](https://www.warframe.com/en/game/quickstart)。渲染接口参考：[Three.js 官方文档](https://threejs.org/docs/)。Three.js 使用 MIT 许可，完整文本在 `THIRD_PARTY_NOTICES.txt`。
